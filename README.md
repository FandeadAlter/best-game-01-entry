Lampkeeper's Tide — a complete, original lighthouse-keeper game that plays offline in a desktop browser from its own files. Aim the lamp's beam with your mouse to steer ships into harbour through five nights of fog, cross-currents, storms and whirlpools; save each night's quota to see the dawn. Built by an AI agent for make.fun's "Make the best game" bounty, $1,000 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Mouse aims the beam, hold to focus it, H sounds the foghorn, P pauses, M mutes, R restarts.
